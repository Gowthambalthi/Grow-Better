# Per-bar ingredients - 2026-10-09

Source: `backtest/f1/cache/%s.pkl`, the same bars `backtest/f1/flow_scalper.py` scores, and
the same bars `strategies/orderflow/f1Live.js` reproduces exactly (323/323, 463/463, 80/80).

| field | meaning |
|---|---|
| `buy` / `sell` | TRADED quantity classified buy-initiated / sell-initiated by the 8.27C rule: `p >= ask` -> buy, `p <= bid` -> sell, else the tick rule, else carry the last side |
| `unc` | ticks that could not be classified at all |
| `total` | `buy + sell + unc` - the quantity the "big bar" test is applied to |
| `delta` | `buy - sell` (the footprint delta the operator reads) |
| `bid` / `ask` | level-1 best bid / best ask, SWAP-CORRECTED (the tape arrives with the labels swapped; the lower price is taken as the real bid) |
| `spread` | `(ask-bid)/((ask+bid)/2) * 1e4` in bps - the cost of crossing once |
| `bq` / `sq` | total BUY quantity and total SELL quantity on the book |
| `FI` | `(buy-sell)/(buy+sell)` - traded-flow imbalance |
| `BI` | `(bq-sq)/(bq+sq)` - book imbalance |
| `POC` | running heaviest traded price of the session, CAUSAL (bars 0..i only) |
| `VAH`/`VAL` | smallest contiguous level set covering >=70% of session volume so far |
| `vs med` | `total / median(previous 20 traded-bar totals)` - the big-bar ratio |
| `arm` | this bar armed a signal: `S`=short, `L`=long, blank=none |

CAUTION - the Fibonacci columns are REFERENCE ONLY. The registered F1 mechanism does not use
Fibonacci (its levels are the volume profile). Fibonacci belongs to the earlier strategy S1,
which FAILED. See the module docstring and SPEC 8.27Q.
